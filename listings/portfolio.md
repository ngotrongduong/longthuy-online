## 1. Egg Heist: Steal & Hatch Pets (live Roblox game)

- Link: https://www.roblox.com/games/126235139339038
- Media: `portfolio/games/eggheist-1.jpg` … `-3.jpg` (store key art).
- Title (Upwork): Egg Heist — live Roblox game: pets, bosses, Robux shop
- Role: Roblox developer (design, Luau systems, creature rigs and motion, store page)
- Description:
  A public Roblox game we built and run end to end (up to 8 players, bots fill empty slots). Players steal eggs
  from boss nests, outrun the boss home, hatch them into pets that earn cash, and train speed to reach outer zones.

  idempotent receipt handling, DataStore saving with session locking, daily/online rewards, quests, rewarded ads.
  The images are the game's store key art.
- Skills: Roblox Studio, Lua, Game Development, 3D Rigging, Game Design

## 4. Rigged low-poly fox (video)

- Media: `portfolio/rigged-fox-demo.mp4`, `portfolio/rigged-fox-1.png` … `-3.png`, files in `portfolio/rigged-fox/`.
- Title (Upwork): Low-poly rigged creature, Roblox-ready (rig, idle, walk)
- Description (as published):
  A stylized low-poly fox built the way we deliver client models for Roblox: 3,808 triangles (from a 120k-triangle
  source), one small texture, pivot at the feet. A 28-bone skeleton with clean weights (max 4 influences per vertex),

  four-beat walk with planted feet. Delivered as .blend, .fbx (idle and walk) and .glb, with a README on importing
  into Roblox Studio.

- Skills: Blender, 3D Rigging, Low Poly, 3D Model
